# Experiments

Drafts and demos of various experiments.

- [`chem-lab/`](chem-lab/) — 2D chemistry lab simulator. Open `chem-lab/index.html` in a browser.
- [`world-editor/`](world-editor/) — geodesic world editor: plates, climate, biomes, landmarks. Open `world-editor/index.html` in a browser.
- [`awards-video/`](awards-video/) — navy & gold awards-night video templates (category intro + nominee clips) rendered to MP4 with Remotion.
