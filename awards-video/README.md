# Awards Night Video Templates

Pre-rendered awards-night videos in navy and gold. Each category becomes one 1920×1080 MP4:

1. **Category intro** (7 s, with music): gold lines draw outward, "The nominees for" fades in, then the category name appears in metallic gold. A light sweep then passes across it.
2. **Nominees**: each nominee's clip plays full screen inside a gold frame with corner accents, with their name and an optional detail line in a lower-third. Clips settle in with a gentle push.
3. **Transitions**: between scenes the picture dips to the navy backdrop while a gold light streak glides across. It alternates left-to-right and right-to-left.
4. A fade to navy at the end, with no winner reveal, so presenters announce the winner.

The backdrop is a 3D space the scene floats in. About 1,100 gold, ivory and pale-blue particles have real positions in depth, viewed through a camera that drifts slowly forward and sways. Far particles fade into navy haze, mid-distance ones are crisp, and near ones go softly out of focus. Faint haze volumes add air. You can tune it in `src/Backdrop.tsx`: `SPEED`, `FOCUS`, `APERTURE` and the particle count.

The font is **Jost**, a free geometric font close to Futura.

## Setup

```bash
cd awards-video
npm install
```

## Add your nominees

1. Put each nominee's clip in `public/clips/`. Use MP4 or MOV, ideally 1920×1080 so it fills the frame without cropping.
2. Edit `data/awards.json`:

```json
{
  "id": "best-newcomer",
  "title": "Best Newcomer",
  "nominees": [
    {"name": "Jane Smith", "detail": "Marketing", "clip": "jane.mp4"}
  ]
}
```

Nominee options:
- `detail`: the second line under the name. Optional.
- `clip`: the file in `public/clips/`. Leave it out and a dashed placeholder appears instead.
- `startAt`: the second to start the clip from. Optional.
- `maxSeconds`: cuts a long clip short. Optional. Otherwise the clip plays at its full length.

Category options:
- `id`: lowercase letters, numbers and hyphens. It becomes the file name.
- `kicker`: the small line above the title. The default is "The nominees for".

## Preview and render

```bash
npm run studio          # live preview in the browser and scrub through it
npm run render          # render every category to out/<id>.mp4
node render-all.mjs best-newcomer   # render one category
```

## Intro music

`public/music/intro.m4a` is an original fanfare generated by `tools/make-intro-music.py`, so there are no licensing concerns. It has a string swell, a timpani roll, a brass chord as the title lands, and chimes with the light sweep. To use your own track, replace that file and keep the name. Set `INTRO_MUSIC` in `src/theme.ts` to `null` for no music, or change `INTRO_MUSIC_VOLUME`. The nominee clips keep their own audio.

## Tweaking the look

Colours, font, intro length and fade timings are in `src/theme.ts`. The intro animation is in `src/CategoryIntro.tsx` and the nominee frame and lower-third are in `src/NomineeClip.tsx`.
