# Awards Night Video Templates

Pre-rendered awards-night videos in navy and gold, at 1920×1080. You make everything in a simple app in your browser.

**For each category**
- **Nominees video** (`<category>.mp4`):
  1. The intro, with music: "The nominees for" and then the category name in metallic gold.
  2. Each nominee's clip, full screen in a gold frame with their name in a lower-third.
  3. Between scenes, a gold light streak passes across.
  4. It ends on the award title card ("And the award for… Best Newcomer") and **holds on that last frame** while the presenters announce the winner.
- **Winner video** (`<category>-winner.mp4`, optional, kept separate so it stays secret):
  1. A reveal with its own fanfare: "Winner", the category, then the name with gold light rays and a burst of sparks.
  2. The winner's (longer) clip with a "Winner · Category" lower-third.
  3. A closing name card that holds on the last frame.

**LED wall screens** (`screen-*.mp4`)
- **Title screen:** your event name and subtitle.
- **Background only:** for behind presenters and speeches.
- **Messages:** any text, e.g. "Welcome / Please take your seats", "Intermission".
- **Countdown:** e.g. "The ceremony begins in 5:00". It counts down, then holds on 0:00.

The title, background and message screens are **48-second seamless loops**, so set the playback software to loop them. The background is a 3D field of gold sparkles that the camera drifts through, with depth of field. It's built so the last frame flows straight into the first.

The font is **Jost**, a free geometric font close to Futura.

## Using the app (easiest)

1. Install **Node.js** (the LTS version) from nodejs.org. You only need to do this once.
2. Double-click the launcher in this folder:
   - **Mac:** `Start Awards.command`. If macOS says it can't be opened, right-click it, choose **Open**, then **Open** again.
   - **Windows:** `Start Awards.bat`
3. The first time, it installs itself, which takes a minute or two. Then the app opens in your browser at http://localhost:4321.

Keep the small terminal window open while you work. Close it to stop the app.

In the app:
- **LED wall screens** (top left): set the event name, then add, edit or remove screens.
- **Categories** (left): add, select, reorder or delete them. Each has a **Nominees video** tab and a **Winner video** tab.
- **Nominees**: type a name and an optional second line. Drop a video onto the box, or click it to choose a file. Optionally set a start time or a maximum length.
- **Add several at once**: drop several clips onto the dashed area under the nominees and you get one nominee per clip, named after the file.
- **Preview**: shows the finished video. It updates when you leave a text field or press Enter; Escape undoes what you typed.
- **Winner**: on the Winner video tab, pick one of the nominees (or someone else), then drop in their longer clip.
- **Render**: renders the video you're looking at. **Render everything** in the sidebar renders all nominee videos, winner videos and screens. Each one shows a progress bar, then **Watch** and **Download** links. Finished files are saved in the `out/` folder (**Open output folder**).

Everything saves automatically to `data/awards.json`, and your clips are copied into `public/clips/`. Nothing leaves your computer. The first render downloads a small browser that's used to draw the frames, so it takes a little longer.

## If rendering fails

- **"No browser found for rendering frames" or a browser error:** quit the app and start it again, then render. The app now clears a half-finished browser download, retries it, and if that still fails, uses Google Chrome or Microsoft Edge if one is installed. If it still fails, install Google Chrome, or delete the folder `node_modules/.remotion` and try again with a working internet connection.
- **Windows antivirus** sometimes quarantines the downloaded render browser. Installing Google Chrome avoids needing it.

## Command line (optional)

```bash
npm install
npm start                # same app, without the launcher
npm run studio           # Remotion Studio preview
npm run render           # render every category in data/awards.json to out/
node render-all.mjs best-newcomer
```

`data/awards.json` can also be edited by hand:

```json
{"id": "best-newcomer", "title": "Best Newcomer", "kicker": "The nominees for",
 "nominees": [{"name": "Jane Smith", "detail": "Marketing", "clip": "jane.mp4", "startAt": 0, "maxSeconds": 10}]}
```

## Intro music

`public/music/intro.m4a` (nominee intros) and `public/music/winner.m4a` (winner reveal) are original fanfares generated by `tools/make-intro-music.py`, so there are no licensing concerns. It has a string swell, a timpani roll, a brass chord as the title lands, and chimes with the light sweep. To use your own tracks, replace those files and keep the names. In `src/theme.ts`, set `INTRO_MUSIC` or `WINNER_MUSIC` to `null` for no music, or change `MUSIC_VOLUME`. The nominee clips keep their own audio.

## Tweaking the look

Colours, font, intro length and fade timings are in `src/theme.ts`. The intro animation is in `src/CategoryIntro.tsx` and the nominee frame and lower-third are in `src/NomineeClip.tsx`.
